# Cyberpunk Analytics Dashboard

A futuristic, cyberpunk-themed product analytics dashboard built with React, Vite, and Recharts.

## Features

- Real-time metrics display
- User growth tracking
- Engagement analytics
- Event stream analysis
- Animated cyberpunk UI with glitch effects
- Responsive design

## Tech Stack

- React 18
- Vite
- Tailwind CSS
- Recharts
- Lucide React Icons

## Local Development

```bash
npm install
npm run dev
```

## Production Build

```bash
npm run build
npm run preview
```

## Docker

Build and run with Docker:

```bash
docker build -t cyberpunk-analytics .
docker run -p 80:80 cyberpunk-analytics
```

## Deployment

Deployed on Nexlayer platform.
